## 3. 数据与契约交付

| 表 | 字段数 | 索引 | 位置 |
| --- | --- | --- | --- |
| `orders` | 19 | PK + 3（phone+created / status+created / created）+ 可选 GIN | `prisma/schema.prisma` |
| `aftersales` | 11 | PK + 3（phone / created / order_id） | 同上 |
| `admin_users` | 5 | PK + username UNIQUE | 同上 |
| `notification_logs` | 8 | PK + 2（created / order_id） | 同上 |

- 引擎：PostgreSQL 16（本地 Docker / 生产云库同版本）
- 契约一致性：字段、类型（`text[]` / `numeric(10,2)` / `timestamptz(3)` / `boolean`）、索引名与 **数据库契约 §13** 逐项一致
- 种子：`SEED_MODE=demo`（管理员 + 2 订单 + 1 售后 + 占位照片）/ `SEED_MODE=admin`（生产仅管理员），**幂等**（连跑 3 次计数不变）

## 5. 本地预览（5 步）

```bash
pnpm install
pnpm db:up                   # 启动本地 PostgreSQL 16（Docker）
cp .env.example .env         # Windows: copy .env.example .env
pnpm hash-password 你的密码   # 把输出粘贴到 .env 的 ADMIN_PASSWORD_HASH
pnpm db:push && pnpm db:seed && pnpm dev
```

| 入口 | 地址 |
| --- | --- |
| 首屏 / 下单 / 成功 | `/` · `/order` · `/success` |
| 售后报修 / 售后成功 | `/aftersale` · `/aftersale/success` |
| 极简后台 | `/admin`（默认账号 `admin`，密码为上面所设） |
