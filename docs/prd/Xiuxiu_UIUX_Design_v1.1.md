## 1. 设计目标与原则

### 1.1 设计目标

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| D1 | 首屏 3 秒内建立信任感 | 用户主观感受：像「正规的、值得托付的」服务平台，而非小广告页 |
| D2 | 降低填写心理负担 | 表单分组清晰、必填项少、错误提示友好 |
| D3 | 关键信息可扫读 | 价格、保修、上门费用规则、联系方式可在一屏内定位 |
| D4 | **APP 级操作手感** | 底部操作栏、抽屉弹层、弹簧动效、毛玻璃导航，达到「像原生 App」的体感 |
| D5 | 弱网与微信环境下观感稳定 | 任何加载状态都有体面兜底，不空白、不错位、不闪烁 |

### 1.2 设计原则

1. **结构学闪修侠，视觉学 Apple**：路径与信息层级参考成熟维修平台的转化结构；观感与控件语言全面对齐 iOS。
2. **内容先行，装饰克制**：动效服务于「专业、干净」，不抢夺表单注意力。
3. **深色区见气质，浅色区见效率**：Hero 用深色营造质感；表单用 iOS 浅色分组列表保证填写效率。
4. **iOS 的三条铁律**：层级靠留白与分组、而非边框阴影；颜色语义化、而非装饰化；交互必须即时反馈。
5. **移动端第一优先级**：所有尺寸、热区、动效先按 375px 与微信内置浏览器校验，桌面端做等比放大。
6. **成本可控**：优先纯 CSS 实现动效与材质，不引入重型素材与动画库（与 PRD 技术约束一致）。

## 2. 参考基准与风格定位

### 2.1 核心参考站：闪修侠（`shanxiuxia.com`）

**定位**：国内手机 / 数码上门维修的代表性平台，其**信息架构与转化结构**作为本项目的一号参考；**视觉语言不照搬**（改为 Apple / iOS 风格）。

**实测拆解（基于站点 wap3.2 结构与样式表）**

| 维度 | 闪修侠的做法 | 本项目的取舍 |
| --- | --- | --- |
| 首页入口结构 | 顶部设备搜索框（「输入维修设备搜索哦~」）→ 品类导航（手机 / 平板 / 电脑 / 配件 / 更多）→ 高频服务快捷入口（电池、屏幕、内存升级、后盖玻璃、上门贴膜） | **✅ 采纳结构，缩减体量**：本项目品类少，改为「两个服务卡（清灰换硅脂 / 其他问题）+ 型号输入」直达，不设全站搜索 |
| 服务呈现 | 品类 → 服务项 → 价格 / 时长 / 保修承诺逐层展开 | **✅ 采纳为原则**：价格与「含 7 天保修」前置到选择卡片上，不让用户点进去才知道价格 |
| 转化路径 | 极短线性路径：选服务 → 下单 → 支付 | **✅ 采纳**：首屏 → 主页 → 表单 → 成功页，全程无注册、无跳转分心 |
| 底部操作 | 大量 `position: fixed` + `.footer-btn` 底部固定操作栏，强 CTA | **✅ 采纳为 APP 式底部操作栏**（含毛玻璃与安全区内边距） |
| 信任背书 | 品牌介绍（成立于 2015）、4 大服务模式（在线定价透明维修、上门极速响应、品质配件无忧售后、统一监管专业培训）、客服电话常驻 | **⚠️ 部分采纳**：本项目体量小，改用「价格透明 + 7 天保修 + 上门规则透明 + 电话/微信双通道」建立信任，不虚构资质 |
| 视觉令牌 | 品牌橙 `#ff8000`（辅助 `#ea7e14`、浅底 `#f8f3ee`）；文字 `#333` / 次要 `#b2b2b2`；分割线 `#e6e6e6`；背景 `#f8f8f8`；强调红 `#df5357` | **❌ 不采纳配色**：本项目品牌为蓝，且改为 iOS 语义化灰阶体系（§3.1） |
| 字号体系 | 主字号偏小（`3.2vw` ≈ 12px 为主，部分 10–14px） | **❌ 不采纳**：可读性不足。本项目正文采用 iOS Body 17px（§3.2） |
| 视口设置 | `maximum-scale=1, user-scalable=no`（禁用缩放） | **❌ 不采纳**：违反无障碍要求，本项目允许缩放（§10） |
| 圆角 | 10px（`2.667vw`）为主，少量 4px / 18px / 22px | **⚠️ 升级**：改用 iOS 连续圆角体系 10 / 12 / 16 / 22（§3.3） |

**一句话结论**：**路径、分组与转化结构参考闪修侠；观感、控件与动效对齐 Apple / iOS；可读性与无障碍取其反面（更规范）。**

### 2.2 视觉语言：Apple / iOS

**设计语言来源**：Apple Human Interface Guidelines（iOS 人机界面指南）。

| iOS 设计要素 | 在本项目中的落地 |
| --- | --- |
| Large Title（大标题） | 主页与售后页顶部大标题，随上滑收缩为导航栏小标题（§5.2） |
| Inset Grouped List（分组卡片列表） | 下单表单、售后表单、后台详情：圆角分组卡片 + 分组标题 + 分组间距（§6.2） |
| Segmented Control | 服务类型、联系偏好、服务方式三项选择（§6.4） |
| Bottom Sheet（半屏抽屉） | 期望时间选择、服务详情说明、图片预览入口（§5.3、§7.6） |
| Fixed Bottom Bar（底部操作栏） | 「提交订单」「提交」主 CTA 固定在底部，毛玻璃材质（§6.10） |
| Materials（毛玻璃材质） | 吸顶导航栏、底部操作栏：`backdrop-filter: blur + saturate` |
| Semantic Colors（语义色） | label / secondaryLabel / separator / fill 体系，禁止硬编码零散色值（§3.1） |
| SF Symbols 风格图标 | 线性、圆角端点、单色，随文字色变化（§11.2） |
| Spring Motion（弹簧动效） | 抽屉上滑、卡片展开、按下反馈使用近似 iOS 弹簧曲线（§8） |
| Continuous Corner（连续圆角） | 卡片与按钮圆角用 `border-radius` 近似 squircle，避免尖锐直角 |
| Safe Area（安全区） | 顶部大标题与底部操作栏均内缩安全区（§9.1） |
| 即时反馈 | 所有可点元素具备按下态；提交、上传、匹配订单均即时反馈（§6.11） |

> **V1 范围声明**：V1 仅实现**浅色模式**（Light Mode）。暗色模式（Dark Mode）所需令牌已在 §3.1 预留，本期不实现，不纳入验收。

### 2.3 风格关键词与避免项

**关键词**：`iOS 原生感` · `深空蓝` · `克制` · `分组清晰` · `呼吸感` · `可信赖`

**避免项**

| 避免项 | 原因 |
| --- | --- |
| 橙色 / 多品牌色混杂 | 与蓝色品牌主色冲突，削弱一致性 |
| 12px 以下正文、密集堆叠信息 | 可读性差，与 iOS 排版原则冲突 |
| 粒子风暴、闪烁、大幅位移动画 | 廉价、耗电、易眩晕 |
| 拟物图标、立体阴影、发光描边 | 风格过时，与「克制」定位冲突 |
| 表单使用彩色背景分区 | 干扰填写视线，iOS 用留白 + 分组标题表达层级 |
| 长按才出现的关键操作（无可见入口） | 微信环境与中老年用户不可发现 |

## 3. 设计系统

### 3.1 色彩系统

**品牌主色（唯一）**：蓝色。色值由本文档权威定义，PRD 通过硬约束引用。

| 令牌 | 浅色模式值（V1） | 语义 / 用途 | 暗色模式预留值（V1 不实现） |
| --- | --- | --- | --- |
| `--color-primary` | `#2F6BFF` | 主按钮、链接、选中态 | `#5B8CFF` |
| `--color-primary-active` | `#1E4FD8` | 按下 / hover | `#3F6FE0` |
| `--color-primary-soft` | `rgba(47,107,255,.12)` | 选中卡片底、Chip 选中底 | `rgba(91,140,255,.20)` |
| `--color-glow-a` | `#2F6BFF` | 动态背景光晕 A | `#1E4FD8` |
| `--color-glow-b` | `#22D3EE` | 动态背景光晕 B | `#0E7C90` |
| `--color-surface-dark` | `#0A1220` | 首屏 / Hero 深色底 | 同 |
| `--color-text-on-dark` | `#FFFFFF` | 深色区主文字 | 同 |
| `--color-text-on-dark-2` | `#B8C4D9` | 深色区次要文字 | 同 |
| `--color-label` | `#111827` | 浅色区主文字（≈ iOS label） | `#F5F7FB` |
| `--color-label-2` | `#6B7280` | 次要文字 / placeholder（≈ secondaryLabel） | `#A0A8B8` |
| `--color-label-3` | `#9AA3B2` | 三级文字、说明（≈ tertiaryLabel） | `#79808F` |
| `--color-bg` | `#F5F7FB` | 页面底（≈ systemGroupedBackground） | `#0B1020` |
| `--color-surface` | `#FFFFFF` | 分组卡片底（≈ secondaryGroupedBackground） | `#161C2B` |
| `--color-fill` | `#F2F4F8` | 输入框/内嵌控件底（≈ systemGray6） | `#1F2637` |
| `--color-separator` | `#E5E8EF` | 分组内行分隔线（≈ separator） | `rgba(255,255,255,.12)` |
| `--color-warning` | `#F59E0B` | 上门提示、注意事项 | `#FFB340` |
| `--color-success` | `#10B981` | 「保修期内」、成功态 | `#30D158` |
| `--color-danger` | `#EF4444` | 表单错误（建议扩展色，待确认） | `#FF453A` |

**使用规则**

- **单主色原则**：可点击元素只用 `--color-primary` 系；`--color-warning` 仅用于提示，不得用于按钮。
- **iOS 语义优先**：写样式时引用语义令牌（label / separator / fill），不直接写十六进制色值。
- **深色区不加白底卡片**：避免「暗底贴白块」的割裂感。
- **错误态用色 + 图标 + 文案三通道**，不可仅靠颜色表达。
- `--color-label-3`（`#9AA3B2`）仅用于非正文装饰（如钉子文字、分割提示）；正文与说明文字必须使用 `--color-label-2`（`#6B7280`，对比度 ≥4.5:1）。

### 3.2 字体与排版（iOS 文本样式体系）

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro SC", "PingFang SC",
             "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

| 语义样式 | 字号 / 行高 | 字重 | 本项目用途 |
| --- | --- | --- | --- |
| Large Title | 34 / 41 | 700 | 主页 / 售后页顶部大标题（移动端可降至 30 / 38） |
| Title 1 | 28 / 34 | 600 | 成功页主标题、后台页标题 |
| Title 2 | 22 / 28 | 600 | 区块标题（「选择服务」「联系信息」） |
| Title 3 | 20 / 25 | 600 | 卡片主标题、套餐名 |
| Headline | 17 / 22 | 600 | 列表行主文案、按钮文字、价格 |
| Body | 17 / 24 | 400 | 正文、表单输入内容 |
| Callout | 16 / 21 | 400 | 次级正文、说明段落 |
| Subheadline | 15 / 20 | 400 | 提示条正文、表单辅助说明 |
| Footnote | 13 / 18 | 400 | 字段提示、隐私说明、时间戳 |
| Caption 1 | 12 / 16 | 400 | 最小字号（不得再小）：角标、版权、店名小字 |

**排版规则**

- 正文与输入框 **17px**（≥16px，满足 PRD 硬约束且对齐 iOS Body）。
- 中文行高 ≥ 1.4；段落最大宽度：移动端满宽减 32px，桌面端 ≤ 720px。
- 深色区文字统一附 `text-shadow: 0 1px 8px rgba(0,0,0,.5)` 作为可读性兜底。
- 价格写法：`¥80`、`¥100`；「起」前留一个空格（`¥80 起`）。金额、电话、单号使用 `font-variant-numeric: tabular-nums`。
- 不使用 Web 字体；不全局禁用缩放。

### 3.3 间距 / 圆角 / 材质 / 阴影 / 层级

**材质（Materials）**

```css
/* 导航栏 / 底部操作栏毛玻璃 */

backdrop-filter: saturate(180%) blur(20px);
```

## 8. 动效规范

### 8.1 动效原则

- 只用于三类目的：**表达层级、反馈状态、平滑过渡**；不做纯装饰动画。
- 时长：反馈 ≤120ms，过渡 200–350ms，环境类（背景）24–30s 起步。
- 仅驱动 `transform` / `opacity`；禁止动画化 `width/height/top/left/box-shadow`。
- 曲线：交互反馈与抽屉用 `--ease-spring`（近似 iOS 弹簧），环境类用 `--ease-in-out`。
- `prefers-reduced-motion: reduce` 时：环境类动画停止，过渡类压缩为直接切换。

### 8.2 动态背景（兜底视觉）参数

| 项 | 参数 |
| --- | --- |
| 底色 | `#0A1220`（深空蓝，非纯黑） |
| 光晕数量 | 2–3 团 |
| 实现 | `radial-gradient`，A `#2F6BFF`、B `#22D3EE` |
| 尺寸 | 单团直径 ≥120vw，超出屏幕 |
| 透明度 | 20%–35% |
| 动画 | `translate3d` 位移 ≤6% 视口 + `scale` 1.00→1.08 |
| 循环 | 24–30s/循环，多团错开延迟（0 / -8s / -16s） |
| 缓动 | `ease-in-out` |
| 禁止 | 粒子、闪烁（>3Hz）、位移 >10%、亮度突变 |
| 降级 | reduced-motion → 静态渐变（保留色彩层次） |

### 8.3 关键动效清单（APP 化）

| 场景 | 动效 | 参数 |
| --- | --- | --- |
| 首屏 → 主页 | 交叉淡入淡出 | 300ms `--ease-out` |
| 页面前进 / 返回 | 右滑入 / 左滑出 + 淡入 | 300ms `--ease-spring`（reduced-motion 时纯淡入淡出） |
| Large Title 收缩 | 字号 30→17、左移入导航栏、导航底渐显 | 与滚动 0–60px 线性映射 |
| 视频就绪 | 淡入覆盖兜底背景 | 800ms 线性 |
| 视频失败 | 直接保持兜底 | 无过渡（禁止闪白/闪黑） |
| Segmented 切换 | 滑块位移 | 200ms `--ease-spring` |
| 分组区展开 / 收起 | 高度 + 透明度过渡 | 200ms |
| Bottom Sheet | 上滑入场 / 下滑退场 + 遮罩淡入 | 350ms `--ease-spring` |
| 按钮按下 | `scale(.97)` + 底色加深 | 120ms `--dur-instant` |
| 校验失败 | 字段 / 标签组抖动一次（±4px） | ≤200ms |
| 提交中 | 按钮内环形指示器 | 800ms/圈 |
| 二维码高亮 | 放大 150ms + 呼吸光晕 3s/循环 | reduced-motion 时静态 |
| Toast | 上移淡入 / 淡出 | 200ms / 停留 2.5s / 200ms |
| 后台状态变更 | 行内高亮 | 600ms |

## 9. 响应式与微信内浏览器适配

### 9.1 移动端适配清单

| 项 | 要求 |
| --- | --- |
| 视口 | `width=device-width, initial-scale=1, viewport-fit=cover`；**允许缩放**（不设 `maximum-scale` / `user-scalable`） |
| 安全区 | 底部操作栏 / 底部信息区加 `padding-bottom: env(safe-area-inset-bottom)`；导航栏加 `env(safe-area-inset-top)` |
| 高度 | 优先 `dvh`，`100vh` 仅作回退 |
| 键盘 | 底部操作栏监听 `visualViewport` 跟随键盘；若实现不稳定，则在输入聚焦时下沉隐藏 |
| 输入缩放 | 输入框 17px（≥16px），iOS 聚焦不放大页面 |
| 长按选中 | 非文本区域 `user-select: none`；单号、电话、地址保持可选中复制 |
| 横屏 | 表单保持单列；Hero 高度改 `min(60vh, 420px)` |
| 毛玻璃兜底 | `backdrop-filter` 不支持时回落 `rgba(255,255,255,.96)` |

### 9.2 微信内置浏览器专项

| 项 | 处理方式 |
| --- | --- |
| 视频内联播放 | `<video playsinline webkit-playsinline x5-playsinline muted loop>`；iOS 必须 `muted` 才可自动播放 |
| 自动播放被拒 | 捕获 `play()` rejection → 立即降级为动态背景（不得停留在空白视频层） |
| 长按识别二维码 | 必须 `<img>` + 白底 + 无覆盖（§6.7） |
| 页面分享 | 设置 `og:` / `title` 元信息，保证分享卡片标题与缩略图正常 |
| 字体渲染 | Android X5 内核中文偏粗：正文使用 400 字重，避免 300 |
| 缓存策略 | 静态资源带 hash；关键首屏 CSS 内联并带版本号 |
| 外链下载 | 页面内不出现文件下载按钮（微信易拦截）；本期无支付与下载 |

### 9.3 桌面端

- 表单居中最大宽 560px；Hero 全宽，内容最大宽 1200px。
- 底部固定操作栏取消，改为表单内按钮；hover 态用 `@media (hover: hover)` 包裹。
- 键盘可达：Tab 顺序与视觉顺序一致，聚焦环清晰。

## 10. 无障碍与可用性

| 项 | 要求 |
| --- | --- |

## 附录 B：修机视频拍摄脚本（可选素材）

**设备**：手机 + 三脚架 / 支架即可，横屏拍摄，30fps，1080p。

**分镜表（每镜约 2 秒，成片 8–15 秒）**

| # | 画面内容 |
| --- | --- |
